1. Sintaks Factory Constructor

  • Pada program ini, factory constructor digunakan untuk membuat objek melalui method khusus yang mengembalikan instance dari class.
  • Class MyClass memiliki dua cara pembuatan objek, yaitu melalui generative constructor dan factory constructor.
  • Factory constructor create() bertugas membuat dan mengembalikan objek MyClass.
  • Penggunaan factory constructor memberikan fleksibilitas dalam proses pembuatan objek.
  • Pada fungsi main(), program membuat dua objek menggunakan constructor yang berbeda.
  • Program kemudian menampilkan pesan bahwa objek berhasil dibuat.

  // Generative constructor
  MyClass();

  // Factory constructor

2. Kasus 1 – Singleton Pattern

  • Pada program ini, singleton pattern digunakan untuk memastikan bahwa hanya ada satu objek DatabaseConnection yang dibuat selama program berjalan.
  • Constructor DatabaseConnection._internal() dibuat private sehingga objek tidak dapat dibuat secara langsung dari luar class.

  • Factory constructor mengembalikan instance yang sama setiap kali objek diminta.
  • Pada fungsi main(), dua variabel dibuat menggunakan constructor yang sama, tetapi keduanya mengacu pada objek yang sama.

class DatabaseConnection {

3. Kasus 2 – Object Pool / Caching

  • Pada program ini, factory constructor digunakan untuk menerapkan konsep Object Pool atau Caching.
  • Setiap koneksi yang telah dibuat akan disimpan ke dalam variabel _cache.
  • Jika terdapat permintaan koneksi dengan host dan port yang sama, program akan mengembalikan objek yang sudah ada.
  • Jika koneksi belum tersedia pada cache, program akan membuat objek baru dan menyimpannya ke dalam cache.
  • Teknik ini dapat menghemat penggunaan memori dan meningkatkan efisiensi aplikasi.
  • Pada fungsi main(), program membuat beberapa koneksi dan membandingkan apakah objek yang digunakan sama atau berbeda.

// ==========================================
// Nama  : Muhammad Bagas putra andeza
// NIM   : 251410003
// Kelas : SI2A
// ==========================================

class ConnectionPool {
  final String host;
  final int port;

  static final Map<String, ConnectionPool> _cache = {};

  ConnectionPool._(this.host, this.port);

  factory ConnectionPool(String host, int port) {
    var key = '$host:$port';

    if (_cache.containsKey(key)) {
      print('Returning cached connection for $key');
      return _cache[key]!;
    }

    print('Creating new connection for $key');
    var connection = ConnectionPool._(host, port);
    _cache[key] = connection;

    return connection;
  }

  void query(String sql) {
    print('Executing: $sql on $host:$port');
  }
}

void main() {
  var conn1 = ConnectionPool('localhost', 5432);
  conn1.query('SELECT * FROM users');

  print('');

  var conn2 = ConnectionPool('localhost', 5432);
  conn2.query('INSERT INTO products VALUES ("Laptop")');

  print('');

  var conn3 = ConnectionPool('db.example.com', 3306);
  conn3.query('UPDATE orders SET status="Shipped"');

  print('');
  print('conn1 dan conn2 sama? ${identical(conn1, conn2)}');
  print('conn1 dan conn3 sama? ${identical(conn1, conn3)}');
}

class AppConfig {

  AppConfig._development()
      : environment = 'development',
        apiUrl = 'http://localhost:3000',
        debugMode = true;

    print('API URL : $apiUrl');
    print('Debug Mode : $debugMode');
    print('------------------------');
  }

  var prod = AppConfig.fromEnvironment('prod');
  var stage = AppConfig.fromEnvironment('stage');

  dev.printConfig();
  prod.printConfig();
  stage.printConfig();
}

6. Factory dengan Named Constructors

  • Pada program ini, factory constructor digunakan untuk membuat objek User melalui beberapa cara yang berbeda.
  • Class User berfungsi untuk menyimpan data pengguna berupa ID, nama, dan email.
  • Factory constructor fromJson() digunakan untuk membuat objek User dari data JSON yang diterima.
  • Factory constructor guest() digunakan untuk membuat objek pengguna tamu dengan data default yang telah ditentukan.
  • Factory constructor create() digunakan untuk membuat objek pengguna baru berdasarkan data yang diberikan.
  • Program kemudian menampilkan informasi setiap objek User yang berhasil dibuat menggunakan factory constructor yang berbeda.

// NIM   : 251410003

// ==========================================

class User {
  final String id;
  final String name;
  final String email;

  User._({
    required this.id,
    required this.name,
    required this.email,
  });

  factory User.fromJson(Map json) {
    return User._(
      id: json['id'],
      name: json['name'],
      email: json['email'],
    );
  }

  factory User.guest() {
    return User._(
      id: '0',
      name: 'Guest',
      email: 'guest@example.com',
    );
  }

  factory User.create(String name, String email) {
    return User._(
      id: '001',
      name: name,
      email: email,
    );
  }

  @override
  String toString() {
    return 'User(id: $id, name: $name, email: $email)';
  }
}

void main() {
  var user = User.fromJson({
    'id': '123',
    'name': 'Alice',
    'email': 'alice@example.com'
  });

  var guest = User.guest();
  var newUser = User.create(
    'Bob',
    'bob@example.com',
  );

  print(user);
  print(guest);
  print(newUser);
}

7. Factory dengan Generic

  • Pada program ini, factory constructor digunakan bersama Generic untuk membuat objek response dengan tipe data yang fleksibel.
  • Class Response berfungsi sebagai class dasar yang menyimpan data atau pesan error.
  • Factory constructor success() digunakan untuk membuat objek SuccessResponse yang berisi data berhasil.
  • Factory constructor error() digunakan untuk membuat objek ErrorResponse yang berisi pesan kesalahan.
  • Generic memungkinkan class Response digunakan untuk berbagai tipe data tanpa perlu membuat class baru.
  • Program kemudian menampilkan data yang berhasil dimuat dan pesan error sesuai objek yang dibuat.

// ==========================================
// Nama  : Muhammad Bagas putra andeza
// NIM   : 251410003
// Kelas : SI2A
// ==========================================

abstract class Response<T> {
  final T? data;
  final String? error;

  Response({this.data, this.error});

  // Factory untuk success
  factory Response.success(T data) = SuccessResponse<T>;

  // Factory untuk error
  factory Response.error(String error) = ErrorResponse<T>;
}

class SuccessResponse<T> extends Response<T> {
  SuccessResponse(T data) : super(data: data);
}

class ErrorResponse<T> extends Response<T> {
  ErrorResponse(String error) : super(error: error);
}

void main() {
  Response<String> success = Response.success('Data berhasil dimuat');
  Response<String> error = Response.error('Gagal memuat data');

  print('Success Data : ${success.data}');
  print('Error Message : ${error.error}');
}

9. Factory vs Static Method

  • Pada program ini ditunjukkan perbedaan antara Factory Constructor dan Static Method dalam membuat objek.
  • Class Example memiliki constructor privat yang hanya dapat diakses dari dalam class.
  • Factory constructor create() digunakan untuk membuat dan mengembalikan objek Example.
  • Static method createStatic() juga digunakan untuk membuat objek Example, tetapi merupakan metode statis biasa.
  • Factory constructor harus mengembalikan instance class atau subclass, sedangkan static method dapat mengembalikan tipe data apa saja.
  • Program kemudian membandingkan objek yang dibuat dan menampilkan hasilnya ke layar.

// ==========================================
// Nama  : Muhammad Bagas putra andeza
// NIM   : 251410003
// Kelas : SI2A
// ==========================================

class Example {
  Example._();

  // Factory Constructor
  factory Example.create() => Example._();

  // Static Method
  static Example createStatic() => Example._();
}

void main() {
  var e1 = Example.create();
  var e2 = Example.createStatic();

  print('e1 dibuat melalui konstruktor pabrik: $e1');
  print('e2 dibuat melalui metode statis: $e2');

  if (e1 != e2) {
    print('e1 dan e2 adalah instansi yang berbeda, seperti yang diharapkan.');
  }
}

10. Factory untuk Immutable Objects dengan Cache

  • Pada program ini, factory constructor digunakan untuk membuat objek warna yang bersifat immutable dan disimpan dalam cache.
  • Class Color menyimpan nilai RGB yang tidak dapat diubah setelah objek dibuat.
  • Factory constructor rgb() akan memeriksa cache sebelum membuat objek baru.
  • Jika kombinasi warna yang sama sudah pernah dibuat, objek yang ada di cache akan digunakan kembali.
  • Teknik ini membantu menghemat penggunaan memori karena objek yang sama tidak dibuat berulang kali.
  • Program kemudian membuktikan bahwa dua objek dengan nilai RGB yang sama dapat merujuk pada instance yang sama.

// ==========================================
// Nama  : Muhammad Bagas putra andeza
// NIM   : 251410003
// Kelas : SI2A
// ==========================================

class Color {
  final int red;
  final int green;
  final int blue;

  static final Map<String, Color> _cache = {};

  Color._(this.red, this.green, this.blue);

  factory Color.rgb(int red, int green, int blue) {
    if (red < 0 || red > 255 || green < 0 || green > 255 || blue < 0 || blue > 255) {
      throw ArgumentError('RGB values must be 0-255');
    }

    var key = '$red,$green,$blue';

    if (!_cache.containsKey(key)) {
      _cache[key] = Color._(red, green, blue);
    }

    return _cache[key]!;
  }

  factory Color.red() => Color.rgb(255, 0, 0);
  factory Color.green() => Color.rgb(0, 255, 0);
  factory Color.blue() => Color.rgb(0, 0, 255);
  factory Color.white() => Color.rgb(255, 255, 255);
  factory Color.black() => Color.rgb(0, 0, 0);

  @override
  String toString() => 'Color($red, $green, $blue)';
}

void main() {
  var red1 = Color.red();
  var red2 = Color.rgb(255, 0, 0);

  print(red1);
  print(red2);
  print(red1 == red2);
}

class DatabaseConnection {

  DatabaseConnection(this.id);

  void connect() {
    print('Menggunakan koneksi database #$id');

class ConnectionFactory {
  static final List<DatabaseConnection> _pool = [];

  static DatabaseConnection getConnection() {
    if (_pool.isNotEmpty) {
      return _pool.removeLast();
    }

    return DatabaseConnection(
      DateTime.now().millisecondsSinceEpoch,
    );
  }

  static void releaseConnection(
      DatabaseConnection connection) {
    _pool.add(connection);
  }
}

12. Challenge – AnimalFactory

  • Pada program ini, factory constructor digunakan untuk membuat berbagai jenis objek hewan berdasarkan input pengguna.
  • Class Animal berperan sebagai class abstrak yang menjadi induk dari beberapa jenis hewan.
  • Berdasarkan parameter yang diberikan, factory constructor akan membuat objek Cat, Dog, atau Bird.
  • Program menerapkan cache sehingga objek hewan dengan atribut yang sama dapat digunakan kembali tanpa membuat objek baru.
  • Validasi dilakukan untuk memastikan nama hewan tidak kosong dan jenis hewan yang dimasukkan valid.
  • Program kemudian menampilkan suara masing-masing hewan dan membuktikan bahwa cache bekerja dengan membandingkan dua objek yang sama.

// ==========================================
// Nama  : Muhammad Bagas putra andeza
// NIM   : 251410003
// Kelas : SI2A
// ==========================================

abstract class Animal {
  final String name;

  Animal(this.name);

  void sound();

  static final Map<String, Animal> _cache = {};

  factory Animal.create(
    String type,
    String name,
  ) {
    if (name.isEmpty) {
      throw ArgumentError(
          'Nama hewan tidak boleh kosong');
    }

    String key = '$type-$name';

    if (_cache.containsKey(key)) {
      return _cache[key]!;
    }

    Animal animal;

    switch (type.toLowerCase()) {
      case 'cat':
        animal = Cat(name);
        break;

      case 'dog':
        animal = Dog(name);
        break;

      case 'bird':
        animal = Bird(name);
        break;

      default:
        throw ArgumentError(
            'Jenis hewan tidak dikenal');
    }

    _cache[key] = animal;

    return animal;
  }
}

class Cat extends Animal {
  Cat(String name) : super(name);

  @override
  void sound() {
    print('$name : Meow');
  }
}

class Dog extends Animal {
  Dog(String name) : super(name);

  @override
  void sound() {
    print('$name : Woof');
  }
}

class Bird extends Animal {
  Bird(String name) : super(name);

  @override
  void sound() {
    print('$name : Tweet');
  }
}

void main() {
  var cat1 = Animal.create(
    'cat',
    'Milo',
  );

  var dog1 = Animal.create(
    'dog',
    'Buddy',
  );

  var bird1 = Animal.create(
    'bird',
    'Rio',
  );

  var cat2 = Animal.create(
    'cat',
    'Milo',
  );

  cat1.sound();
  dog1.sound();
  bird1.sound();

  print('Cache bekerja: ${cat1 == cat2}');
}

13. Kesimpulan

Dari seluruh pembahasan mengenai Factory Constructor pada bahasa Dart, dapat disimpulkan bahwa:

  • Factory constructor digunakan untuk mengontrol proses pembuatan objek sehingga lebih fleksibel dibandingkan constructor biasa.
  • Factory constructor dapat mengembalikan instance dari class yang sama maupun subclass sesuai kebutuhan program.
  • Factory constructor memungkinkan penerapan pola Factory Pattern untuk menyederhanakan proses pembuatan objek.
  • Factory constructor dapat digunakan untuk melakukan validasi data sebelum objek dibuat sehingga meningkatkan konsistensi program.
  • Factory constructor dapat memanfaatkan cache untuk menghemat memori dengan menggunakan kembali objek yang sudah ada.
  • Factory constructor dapat dikombinasikan dengan Generic, Named Constructor, dan berbagai konsep Object-Oriented Programming (OOP).
  • Seluruh konsep factory constructor membantu menghasilkan kode yang lebih efisien, terstruktur, mudah dipelihara, dan mudah dikembangkan.
